# Case Study Template

**How to use this template:**
1. Copy this file and rename it to `your-project-name.md`
2. Save it in the `projects/` folder
3. Create a folder in `images/your-project-name/` for your images
4. Add your project to the posts array in `script.js`
5. Replace all placeholder text with your content
6. Delete sections you don't need - not every project needs every section
